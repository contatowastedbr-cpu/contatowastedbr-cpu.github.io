WastedBR Uploader

O WastedBR Uploader é uma ferramenta de uso próprio do canal. Ela roda no computador do dono do canal e usa a API oficial do YouTube para enviar os vídeos do canal depois de aprovados manualmente, definir as thumbnails e ler as estatísticas dos próprios vídeos. Ela não é oferecida ao público e não acessa contas de outras pessoas.

Este app usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube.
