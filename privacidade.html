Política de Privacidade do WastedBR Uploader

Última atualização: 16 de novembro de 2026.

1. O que é

O WastedBR Uploader é uma ferramenta de uso próprio do canal Wasted BR no YouTube. Ela roda apenas no computador do dono do canal e serve para enviar os vídeos do próprio canal, definir thumbnails e consultar as estatísticas desses vídeos. Não é oferecida ao público.

2. Uso dos Serviços de API do YouTube

O WastedBR Uploader usa os Serviços de API do YouTube (YouTube Data API v3 e YouTube Analytics API). Ao usar o app, você concorda com os Termos de Serviço do YouTube. O tratamento dos seus dados pelo Google é regido pela Política de Privacidade do Google (http://www.google.com/policies/privacy).

3. Dados acessados, coletados e guardados

Com a autorização do dono do canal (escopos youtube e yt-analytics.readonly), o app:

  • lê a identificação e o nome do canal autorizado;
  • envia vídeos, thumbnails, títulos, descrições, tags e configurações de publicação do próprio canal;
  • lê o status e as estatísticas dos vídeos do próprio canal (visualizações, curtidas, retenção, inscritos).

O app não acessa dados de espectadores, de outras contas ou de outros canais. Não usa cookies, não exibe anúncios e não usa rastreadores.

4. Como os dados são usados, guardados e compartilhados

  • Os dados são usados só para operar o canal Wasted BR e planejar os próximos vídeos.
  • O token de acesso fica guardado apenas no computador do dono do canal, cifrado com a proteção de dados do Windows (DPAPI).
  • As estatísticas do canal ficam apenas nesse computador e são atualizadas pela API periodicamente.
  • Nenhum dado é vendido, compartilhado com terceiros ou enviado para servidores próprios.

5. Como revogar o acesso

O acesso do app à conta Google pode ser revogado a qualquer momento na página de configurações de segurança do Google: https://security.google.com/settings/security/permissions.

6. Exclusão de dados

  • Ao revogar o acesso, o token salvo deixa de funcionar imediatamente.
  • Os dados obtidos pela API e guardados localmente (token e estatísticas do canal) são apagados em até 7 dias após a revogação ou a pedido, pelo e-mail abaixo.
  • As estatísticas guardadas são atualizadas pela API enquanto o app está em uso; as que ficarem 30 dias sem atualização são apagadas.

7. Alterações

Mudanças nesta política são publicadas nesta página com a nova data de atualização.
