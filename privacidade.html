Política de Privacidade do Wasted BR Uploader

Última atualização: 16 de novembro de 2026.

O que é

O Wasted BR Uploader é uma ferramenta de uso próprio do canal Wasted BR no YouTube. Ela roda apenas no computador do dono do canal e serve para enviar os vídeos do próprio canal, definir thumbnails e consultar as estatísticas desses vídeos.

Dados acessados

Com a autorização do dono do canal, pelas APIs oficiais do Google (YouTube Data API v3 e YouTube Analytics API):

  • identificação e nome do canal autorizado;
  • envio de vídeos, thumbnails, títulos, descrições e configurações de publicação;
  • status e estatísticas dos vídeos do próprio canal (visualizações, curtidas, retenção, inscritos).

Como os dados são usados e guardados

  • Os dados são usados só para operar o canal Wasted BR.
  • O token de acesso fica guardado apenas no computador do dono do canal, cifrado com a proteção de dados do Windows.
  • Nenhum dado é vendido, compartilhado com terceiros ou enviado para servidores próprios.
  • A ferramenta não coleta dados de espectadores nem de outras contas.

Serviços do Google

A ferramenta usa os Serviços de API do YouTube. Ao usá-la, valem também os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
